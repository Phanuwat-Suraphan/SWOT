# แบบเก็บข้อมูลโครงการเด็กไทยแก้มใส

เว็บแอปสำหรับเก็บข้อมูลส่ง ตอบออนไลน์ สรุป ประมวลผล และพิมพ์รายงานได้ ครอบคลุมทุกแบบในเอกสาร

เปิดใช้งาน: https://phanuwat-suraphan.github.io/SWOT/

| แบบ | ผู้กรอก | เนื้อหา |
|---|---|---|
| 1 ตารางข้อมูลภาวะโภชนาการ | ครู | จำนวนนักเรียนแต่ละชั้น ตามส่วนสูงตามเกณฑ์อายุ (5 ระดับ) และน้ำหนักตามเกณฑ์ส่วนสูง (6 ระดับ) ปีการศึกษา 2569 ภาคเรียนละ 2 ครั้ง (ต้นเทอม/ปลายเทอม) |
| 2.1 ความรอบรู้ด้านอาหาร | นักเรียน | ความรู้ 8 ข้อ ทัศนคติ 5 ข้อ ทักษะ 5 ข้อ พฤติกรรม 7 ข้อ (ก่อน–หลังทำกิจกรรม) |
| 2.2 พฤติกรรมการบริโภค | นักเรียน | 11 ข้อ + คำถามอาหารปลอดภัย 4 ข้อ (ก่อน–หลังทำกิจกรรม) |

## ความสามารถหลัก

- ข้อคำถามตรงตามเอกสารต้นฉบับครบทุกข้อ ไม่มีคำถามเพิ่ม
- นักเรียนตอบผ่านมือถือ/คอมพิวเตอร์ ผ่านลิงก์หรือ QR Code ระบบตรวจว่าตอบครบก่อนไปตอนถัดไป เลื่อนไปข้อถัดไปให้อัตโนมัติ
- คำตอบไม่หาย: รีเฟรชหรือปิดหน้าโดยไม่ตั้งใจแล้วทำต่อจากเดิมได้, ใช้งานได้แม้ไม่มีอินเทอร์เน็ต (ส่งข้อมูลให้เองเมื่อกลับมาออนไลน์), กันกดส่งซ้ำ
- ทำแบบ 2.1 เสร็จแล้วทำแบบ 2.2 ต่อได้ทันทีโดยไม่ต้องกรอกชื่อซ้ำ
- หน้าติดตามความคืบหน้า: จำนวนผู้ตอบเทียบเป้าหมาย 10 คน/ชั้น และรายชื่อที่ยังไม่ทำ “หลังทำกิจกรรม” หรือยังไม่ทำอีกแบบ, ชื่อที่จับคู่ไม่ได้, คนที่ตอบซ้ำ
- ตารางภาวะโภชนาการรวมยอดและคิดร้อยละอัตโนมัติ และเตือนเมื่อยอดรวมสองตารางไม่ตรงกัน
- รายงานสรุป: สรุปผลโดยย่ออัตโนมัติ, กราฟภาวะโภชนาการและกราฟเปรียบเทียบก่อน–หลัง, ค่าเฉลี่ย/S.D./ระดับ, ร้อยละตอบถูก, ผลต่าง, จับคู่นักเรียนคนเดิม
- พิมพ์ / บันทึกเป็น PDF (เลือกส่วนที่จะพิมพ์ได้) และส่งออกไฟล์ CSV เปิดด้วย Excel
- เก็บข้อมูลใน Google Sheet ของโรงเรียน (ผ่าน `google-apps-script.gs`) หรือเก็บในเครื่องแล้วรวมไฟล์สำรองจากหลายเครื่อง
- ติดตั้งเป็นแอปบนหน้าจอมือถือได้ (Add to Home Screen)

## เริ่มใช้งาน

1. หน้า **ตั้งค่า**: ตรวจข้อมูลโรงเรียน ระดับชั้น และทำตามขั้นตอน “วิธีเชื่อม Google Sheet” (ทำครั้งเดียว)
2. สร้างลิงก์/QR Code ให้นักเรียนตอบแบบ 2.1 และ 2.2
3. ครูกรอกตารางภาวะโภชนาการ แล้วไปที่ **สรุปผลและพิมพ์รายงาน**

## ไฟล์

- `index.html`, `app.js`, `style.css` – ตัวเว็บแอป
- `sw.js`, `manifest.webmanifest`, `icon.svg` – ใช้งานออฟไลน์และติดตั้งบนมือถือ
- `google-apps-script.gs` – โค้ดสำหรับ Google Sheet ของโรงเรียน
- `nutrition/index.html` – พาลิงก์เดิม `/nutrition/` มาที่หน้าหลัก
